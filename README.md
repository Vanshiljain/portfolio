# Vanshil Jain — Portfolio

Personal portfolio site built with React, Tailwind CSS v4, and Framer Motion. Features a custom canvas-based "agent pipeline" background animation, scroll-triggered reveals, and a custom cursor.

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Outputs to `dist/`. Preview the production build locally with `npm run preview`.

## Stack

- [Vite](https://vite.dev/) + React 19
- [Tailwind CSS v4](https://tailwindcss.com/) (via `@tailwindcss/vite`)
- [Framer Motion](https://motion.dev/) for animation
